# Open Source Landscape: AI Companions & Personas

An overview of the current open-source and commercial landscape for AI companions, focusing on the technologies that enable persistent personality and emotional depth.

## Key Projects & Platforms

| Project | Core Features | Technology Stack |
| :--- | :--- | :--- |
| **MyGirlGPT** | Personal AI companion focused on "unfiltered" personality and self-hosting. | LLM + TTS + Image Generation (Stable Diffusion) |
| **a16z Companion App** | Lightweight framework for creating AI companions with memory. | Vector DB (Pinecone/Milvus) + Conversation History |
| **SillyTavern** | Advanced UI for interacting with multiple LLM backends, focused on roleplay. | Extensive "World Info" and "Character Cards" |
| **OpenClaw** | Skills-based framework for adding functional capabilities to personas. | Modular Skills + Tool Use |
| **Character.AI** | Large-scale commercial platform for persona creation. | Proprietary Models + Community-driven Prompting |

## What Works: The Success Factors

Research into the most successful AI personas reveals three critical success factors:

1. **Persistent Memory**: The ability to remember details across weeks or months of interaction is the single biggest driver of perceived "sentience."
2. **Personality Customization**: Moving beyond generic "helpful" prompts to structured character sheets (like the Maya Character Bible).
3. **Multi-Modal Interaction**: Integrating voice, image generation, and text to create a more immersive and "physical" presence.

## The Maya Advantage

While existing projects focus on *interaction*, the Maya Persona Architecture focuses on *architecture*. By utilizing EASM and SENP, Maya moves beyond simple character cards into a structured, evolving psychological framework that is designed to be model-agnostic and reconstructible across different systems.
